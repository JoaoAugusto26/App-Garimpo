O caminho de um vídeo

  1. Você manda

    No Instagram, toque no aviãozinho → Compartilhar em… (ou Mais) → Garimpo. Escreva uma nota, se quiser, e toque em Mandar. Ou cole o link aqui no app; dá para colar vários de uma vez.

  2. O PC baixa sozinho

    A cada 30 minutos, com o PC ligado, o vídeo é baixado e transcrito. Ele passa de Na fila para Esperando análise.

  3. Você pede a análise no PC

    Abra o Claude Code (aba Code, sessão Local, qualquer projeto) e diga:

    analisa os vídeos novos

  4. O veredito volta para cá

    Vale a pena ou Evite, com o motivo, a fonte oficial, o custo, a confiança e os projetos para quem serve. O que chegou desde a última visita ganha Novo.

O que cada situação quer dizer

Na fila
Chegou na fila. O PC ainda não baixou: ele baixa a cada 30 minutos, se estiver ligado.
Esperando análise
Baixado e transcrito. Falta pedir "analisa os vídeos novos" no PC.
Vale a pena · Evite
Analisado. Toque no cartão para ler tudo; o que vale tem o comando de instalar, com o botão Copiar.
Falhou
Não deu para baixar: post só de foto, que pede login ou link quebrado. Toque em Tentar de novo.

As duas abas

Vídeos
Todos os pedidos, por dia. O funil filtra por situação e a lupa busca por ferramenta, nota ou análise. Tocar num projeto (Ultron, Remedicy…) mostra só o que serve para ele.
Ferramentas
A caixa de ferramentas: só o que vale a pena, uma vez por ferramenta. Toque no círculo quando instalar: o PC passa a saber que você já tem e não recomenda de novo.

Em cada cartão: Compartilhar o veredito, Editar a nota (enquanto está na fila) e Remover, com Desfazer logo depois. Segurando o ícone do app: Colar link e Caixa de ferramentas.

Sem o celular

No Claude Code, mande os links direto na conversa:

veja esses vídeos e me diga o que vale a pena: [links]

Também dá para pedir "como tá a fila?" e "resumo da semana".

Quando algo dá errado

O Garimpo não aparece no Compartilhar
Ele foi salvo como favorito, não instalado. No Chrome: ⋮ → Instalar app. No Xiaomi, libere em Configurações → Apps → Chrome → Outras permissões → Atalhos na tela inicial.
"O GitHub recusou o token"
O token venceu (dura 1 ano) ou foi apagado. Abra a Configuração, toque em Criar token no GitHub e salve o novo. O do PC costuma vencer junto: peça ao Claude "como tá a fila?", que ele avisa.
O vídeo fica em Na fila por horas
O PC está desligado ou o download automático parou. Pergunte ao Claude "como tá a fila?".
Repositório recusado
O app recusa repositório público de propósito: os links e as notas ficariam visíveis. A fila tem que ser privada.

O token fica só neste celular e só abre a fila. Se perder o celular, apague o token no GitHub (Settings → Developer settings → Fine-grained tokens).
